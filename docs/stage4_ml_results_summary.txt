STAGE 4 ML RESULTS SUMMARY
==========================

Research Question:
Can IMDb ratings be predicted using movie runtime, genre, and release year?

Dataset:
The cleaned dataset contains 2411 movies after filtering small genre groups.
The features used were runtime, release year, and genre.
The target variable was IMDb rating.

Models Tested:
- Baseline Mean
- Linear Regression
- Ridge Regression
- Decision Tree
- Random Forest
- Gradient Boosting

Model Performance:
            model      MAE     RMSE        R2
 Ridge Regression 0.704344 0.923810  0.254318
Linear Regression 0.705044 0.924973  0.252439
Gradient Boosting 0.716528 0.945556  0.218799
    Random Forest 0.718692 0.951527  0.208901
    Decision Tree 0.776027 1.017118  0.096077
    Baseline Mean 0.825016 1.070716 -0.001699

Interpretation:
The models were compared using MAE, RMSE, and R2 score. The baseline model predicts the average IMDb rating, so useful ML models should perform better than this baseline. If tree-based models such as Random Forest or Gradient Boosting perform better than Linear Regression, this suggests that the relationship between runtime, genre, release year, and IMDb rating is not fully linear. However, IMDb ratings are subjective and depend on many factors that are not included in this dataset, such as acting quality, budget, director, audience expectations, and number of votes. Therefore, the model results should be interpreted as an approximate prediction rather than a perfect explanation of movie ratings.

Main Conclusion:
Runtime, genre, and release year provide some useful information for predicting IMDb rating, but these variables alone are not enough to fully explain audience ratings. This supports the EDA findings: movie length has a relationship with IMDb rating, but other factors also matter.
